Perguntas frequentes

O DLauncher coleta dados pessoais?

Não automaticamente. Os únicos dados armazenados são os que você envia voluntariamente pelo formulário de feedback: texto, versão do app, versão do Android e modelo do dispositivo.

Posso usar sem criar conta?

Sim. O DLauncher não exige cadastro. Basta instalar e definir como launcher padrão.

O Pro é uma assinatura?

Não. O DLauncher Pro é um pagamento único de R$ 9,99 feito diretamente pelo Google Play. Sem mensalidades.

Como defino o DLauncher como launcher padrão?

Após instalar, pressione o botão Home no seu celular. O Android vai perguntar qual launcher usar — selecione DLauncher e escolha "Sempre".

Como solicitar a exclusão dos meus dados?

Acesse a página de exclusão de dados e siga as instruções. A resposta chega em até 10 dias úteis.
